# Security policy

## Report a security problem

Do not open a public issue for a security problem. Use GitHub private vulnerability reporting for this repository.

Include these details:

- the affected version;
- the affected command or endpoint;
- the steps that show the problem;
- the possible effect;
- a safe test case, if available.

Do not include a real token, password, private key, request note, or user record.

## Supported versions

The latest GitHub release receives security fixes. Older releases do not receive separate fixes.
